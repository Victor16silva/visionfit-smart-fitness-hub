ATHEV — SEU APLICATIVO PARA CELULAR

1. Extraia todos os arquivos do ZIP no computador.
2. Abra a pasta ATHEV no VS Code.
3. Execute iniciar-celular.bat no computador.
4. Conecte celular e computador ao mesmo Wi-Fi.
5. Abra no celular o endereço http://...:8000 mostrado no terminal.
6. Na tela do app, toque em Aluno para começar a demonstração.

Para usar apenas no computador: executar iniciar.bat e abrir http://localhost:8000.
Mantenha o terminal e o computador ligados durante o uso.
Não use Live Server: este projeto possui servidor e banco de dados próprios.
